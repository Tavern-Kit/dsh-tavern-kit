# 接回旧对话

选择 DeepSeek 官方 ZIP 或 SillyTavern JSONL，把熟悉的剧情接着聊。

DeepSeek ZIP 可预览会话标题、时间、消息规模与可识别的省略、失败数量，再选中需要的会话迁入。标准一对一 SillyTavern JSONL 还会显示玩家、角色、保留的候选和系统事件归档数量。

相同来源和内容会定位已有对话；有新内容的来源可另存一段新对话。DeepSeek 导入活动消息路线；JSONL 保留当前正文、全部已存 swipe 及其思路，连续同侧消息各自保留，只有角色首句的记录也能迁入。系统事件、扩展和未知字段随原始完整文件保存在本地。

迁入完成后进入「继续聊天」，选择模型即可续聊，也可选择角色和玩家人设、查看剧情备忘。读取、预览和迁入均不调用模型或下载远程资源。完整对话备份会带上原始导出与已迁入的候选。

### JSONL 来源识别

优先使用聊天头 `chat_metadata.integrity` 标识来源；旧记录没有此编号时，使用文件名、人物与开始时间。相同来源的新增内容可以另存。没有编号的旧文件改名后按新来源识别。内容指纹独立取自原文件完整字节；导入不重写原件。

当前 `mes` 与 `extra` 是所选回复的正文和思路；原始 swipe 即使同文也各自保留。当前正文与所选 swipe 不同时，作为额外候选保存并选中，不覆盖旧内容。只有来源明确提供的失败和空回复状态才进入记录，缺少生成时间不推断为失败。

本插件固定复用 DeepSeek Harness 0.2.2-rc.3 的 MIT ZIP 格式读取与消息转换。公开来源见 [SOURCES.md](<SOURCES.md>)，许可原文见 [DEEPSEEK-MIT.txt](<DEEPSEEK-MIT.txt>)。
