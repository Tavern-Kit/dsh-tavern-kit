# 接回旧对话

选择 DeepSeek 官方 ZIP 或 SillyTavern JSONL，把熟悉的剧情接着聊。

预览标题、时间和可识别消息规模，再选择想接回的对话。JSONL 同时显示玩家、角色、保留的候选和归档事件数量；当前回复、全部已存 swipe 与各自思路进入 RP 对话，连续同侧消息保留实际顺序。

相同来源和内容能定位已有对话；有新内容时另存新对话。原始完整 ZIP 或 JSONL 保存在本地，系统事件、扩展和未知字段随原件留存。迁入完成后选择模型继续聊，也可选用角色和玩家人设、查看剧情备忘。完整对话备份带齐原件与已保存候选。

读取和迁入不调用模型或下载远程头像。DeepSeek ZIP 固定复用 DSH 0.2.2-rc.3 的 MIT 格式读取与消息转换。

适配基线：DeepSeek Harness 0.2.2-rc.3，Node.js 24。
