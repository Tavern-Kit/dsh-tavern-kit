# 换个装扮

经典酒馆、好事岛、像素旅店、溪间四时，四套完整主题随时切换。

经典酒馆以窗灯、旧书与黄铜边饰构成藏书室；好事岛使用奶白纸面、暖棕文字和原创读信兔子；像素旅店带有本地中文像素字库、格点窗景与游戏对话框；溪间四时保留 xi4u 原作 3D 庭院，可选择春、夏、秋、冬。每套主题都包含布局、控件、字体与插画。聊天小按钮与状态签使用同一套主题材料，保留完整触达区；书口、花叶、星灯与季节庭院分别融入阅读边缘。手机四时也能看见真实庭院风物。

页面配色默认跟随系统，也能固定浅色或深色。庭院季节单独保存，不随配色改变。字号、阅读宽度、气泡与本地背景继续保留；刷新或重连后恢复，切换装扮不改变对话。

在装扮页导入本地主题 ZIP，查看预览、名称、版本和作者后选择使用；同 ID 文件先确认再替换。「导出主题」带齐描述、布局 CSS、图片、字体与许可，可在另一份安装中导入使用。「导出这套偏好」另行保存个人显示设置。

经典酒馆、好事岛与溪间四时的中文使用设备字体，拉丁和数字采用本地 Nunito；像素旅店使用本地 Fusion Pixel。主题资源在本地解析，场景只管理自身展示，外观卸载后聊天仍能继续使用。

适配基线：DeepSeek Harness 0.2.2-rc.3，Node.js 24。
