# 连接模型

沿用 DSH 连接，也能填写自己的服务。

「沿用 DSH 连接」直接使用已有 provider、模型和凭据引用；「添加连接」填写 API 地址与聊天 key，再拉取模型。展示名与原始 ID 分开保存，请求使用完整原始 ID。

高级设置可查看能力来源、调整输入预算和参数支持、确认在线目录候选，或设置有序备用链。配置备用链后，默认报错就尝试下一条；可按返回文本或明确正则限定触发。已经输出的正文保留，不拼接另一模型的回复。

账号入口支持目标 new-api 认证族的登录、二次验证、本人分组与模型、账户额度及已有 key 绑定。账号站点和模型 API 地址可分别填写。账户认证与聊天 key 分开管理。社区伙伴的地址模板点击后才应用，手填连接保持直接入口。

适配基线：DeepSeek Harness 0.2.2-rc.3，Node.js 24。
