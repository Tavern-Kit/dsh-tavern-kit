# Tavern Kit

接回旧对话，带上角色卡，接着聊。

一次启用素材库、旧对话迁入、RP 会话、模型连接和四套可分发主题：经典酒馆、好事岛、像素旅店、溪间四时。首页保留「接回旧对话」「带上角色卡」「继续聊天」三个入口；主题支持系统深浅色，溪间四时提供原作 3D 四季庭院。

旧对话可从 DeepSeek ZIP 或 ST JSONL 接回；素材库保存多套「我的人设」，世界书、预设与正则提供专用编辑和本地试跑，聊天内能搜索旧正文。

先接入已有 DSH 连接，或填写自己的服务。开源套件不绑定某个模型站点；社区伙伴信息只在连接推荐位置出现。

需要单独整理卡片时可只安装素材库；连接和外观也可独立使用。单独启用 RP 会话需要素材库与模型连接，旧对话迁入还需要 RP 会话。组合安装包负责一次启用这些依赖。

适配基线：DeepSeek Harness 0.2.2-rc.3，Node.js 24。
