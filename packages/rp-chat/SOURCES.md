# Sources and licenses

Tavern Kit is distributed under AGPL-3.0-only. This package uses the public DeepSeek Harness 0.2.2-rc.3 interfaces; the original MIT license is included in DEEPSEEK-MIT.txt.

- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), 0.2.2-rc.3, MIT: public Cordis services, prepared LLM calls, remote protocol and main-panel lifecycle contracts. The installed runtime and native Session implementation are not modified.
- [SillyTavern](https://github.com/SillyTavern/SillyTavern/tree/063141e433ac8bcd8eaeaa2c072c2ced299e61a4), AGPL-3.0: source reference for prompt block ordering, depth insertion, basic worldbook keyword logic and regex placement. The runtime supports prompt ordering, depth insertion, constant and keyword-triggered worldbooks, and regex transforms with separate model/display projections.
- [dsh-Go](https://github.com/ccch1mneyyy/dsh-Go/tree/246f503a1f51720091cbef173150fdf3939a23d4), AGPL-3.0: source reference for original/editable material separation, deterministic prompt assembly, display windows, Host-owned generation with UI subscriptions, and stable composer focus/send/stop behavior. Original-text preservation and save/cancel semantics inform Tavern Kit's inline editor. No Flutter or Dart runtime is distributed.
- [MagVarUpdate](https://github.com/MagicalAstrogy/MagVarUpdate/tree/d03b7dc8a6ebf9bd611c7e2dc91f3b35462deebc), MIT, Copyright (c) 2025 MagicalAstrogy & StageDog: finite native MVU initialization, updates, schema and message-variable macros, with dsh-Go as the integration reference. Original notice and adaptation details are retained in [the MVU source directory](src/mvu/SOURCE.md) and its [full license](src/mvu/LICENSE-MagVarUpdate). No card JavaScript runtime is loaded.
- [React Flow](https://github.com/xyflow/xyflow), @xyflow/react 12, MIT: interactive map canvas, controls and node interactions.
- [react-markdown](https://github.com/remarkjs/react-markdown) 10.1.0 and [remark-gfm](https://github.com/remarkjs/remark-gfm) 4.0.1, MIT: semantic Markdown reading with original HTML left unexecuted and remote image nodes presented as explicit links. Reading does not rewrite stored input or reply text.
- [Lucide](https://github.com/lucide-icons/lucide), lucide-react, ISC: consistent interface icons for navigation, replies and reading controls.
- [Pixelarticons React](https://github.com/nicholuassommer/pixelarticons-react), @nsmr/pixelart-react 2.0.0, MIT (Copyright 2019 Gerrit Halfmann): 22 original SVG assets are preserved locally in `src/assets/pixelarticons/` with the complete MIT license. `PixelArtwork.ts` contains their exact path data; the favorite fill uses the same icon's outer contour. No third-party icon runtime is required. Line icons use Lucide when no themed artwork is supplied.
- [Kubai Icons](https://github.com/kubai087/kubai-icons/tree/bc3e32102c5679f1f9ddaec7bf0dd402b9f6d9f3), MIT. The selected 16-unit duotone paths are stored in [the artwork directory](src/assets/kubai-icons/paths.ts) with the [original MIT notice](src/assets/kubai-icons/LICENSE). Tavern Kit supplies the themed fills, hover poses and original courtyard window.
- [fflate](https://github.com/101arrowz/fflate), MIT, and [Zod](https://github.com/colinhacks/zod), MIT: portable conversation archives and validated external data.

This package owns one independent RP store. It does not mirror successful candidates into native Session events.
