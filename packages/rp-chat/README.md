# 继续聊天

把剧情、候选和备忘留在一段对话里。

从首页进入「继续聊天」或选择一张角色卡开聊。选择已有连接和一套「我的人设」，或继续手填称呼；世界书、预设和玩家设定在对话设置中调整，人设版本与本地头像随剧情保留。

「换个回复」保留已有候选，序号可直接跳转，喜欢标记便于找回。手改在原文位置展开，取消立即返回阅读，保存失败保留改稿；明确保存会另存一条候选，原回复和原有后续都保留。发送与停止在同一位置响应，准备发送时可继续写下一句，返回结果不清除新稿。开启并发后，同一模型同时生成几个回复，逐条停止或选择一条接着聊。

长聊时可读、可修剧情备忘并锁定重要约定。「继续写」沿用来源候选的冻结设定和实际出字模型。剧情地图先预览，再明确从节点继续。模型与用量明细可查看每次实际请求。

「把这段对话带走」导出单会话完整备份，包含分支、候选、素材版本、原件、备忘及用量。恢复成新对话后选择当前 DSH 连接即可继续。生成属于 Host；离开面板不停止生成，主动停止或卸载插件才取消对应请求。

「搜索正文」可在当前或全部本地对话中找旧候选和分支，先看原文，再明确从这里继续；查询不触发生成。

「剧情变量」显示当前候选的 MVU 状态，可逐字段调整或使用完整 JSON 修订。角色的 `[initvar]`、变量读取宏及有限更新命令在本地处理；每条候选独立保存，续写沿来源状态，停止／失败不提前结算。手改正文沿用原变量，明确保存变量才建立修订；完整备份带齐状态、修订和当时的输入种子。

## 安装与开发

推荐通过 DSH 的插件管理入口安装 `@tavern-kit/suite` 组合包。本目录是 `@tavern-kit/rp-chat` 的源码；开发、构建和本地安装参见项目根 README。
