# 素材库

酒馆卡在本地导入和保存，全程不联网。

选择「导入素材」带入角色卡、世界书、预设和正则，可一次选择多个文件。PNG、JSON、CharX 和已支持的单素材 ZIP 均在本地主机解析。卡内的远程链接不会被下载，头像预览使用包内资源。

素材卡片可搜索、分类、启停、复制和移出。详情里分别展示「本次使用」与「原文件已保存」。保存编辑会新增版本；已经开始的对话仍绑定原版本，需在对话中明确应用新版。移出素材库保留旧对话需要的版本与原件。

「导出原件」保留导入字节；「导出当前版本」输出约定的 JSON。角色输出 CCv3 JSON，未知字段随编辑内容保留。素材位置可在面板中查看。

## 我的人设

选择「新建我的人设」，填好昵称、玩家设定与本地头像，保存自己的角色名片。可以为不同故事保存多套人设；开聊时选用某一版本，之后在对话中手调称呼与设定只影响那段对话。素材库里改好后，已经绑定的对话通过「应用到这段对话」更新。

人设可复制、移出、导出和重新导入；本地头像随所用版本保留，完整对话备份也会带上。头像用于阅读身份，不自动作为模型图片输入。

## 直接编辑条目

- 世界书：选择条目，调整启停、主副关键词、内容、常驻、扫描与预算、顺序、位置、消息角色和深度。
- 预设：选择提示词，调整启用状态、消息角色、内容、顺序和深度。占位块仍使用角色、历史与世界书的实际内容。
- 正则：调整查找与替换规则、输入／输出位置及显示／模型范围；填一小段文本后「本地试运行」，查看匹配、替换结果或规则错误。

表单先改草稿，点击「保存为新版本」才写入素材库。高级原始 JSON 与表单共用修订方法，未知扩展字段保留；试运行不调用模型，也不改对话原文。
