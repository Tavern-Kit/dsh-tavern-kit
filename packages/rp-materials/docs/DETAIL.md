# 素材库

酒馆卡在本地导入和保存，全程不联网。

选择「导入素材」带入角色卡、世界书、预设和正则，可一次选择多个文件。PNG、JSON、CharX 和已支持的单素材 ZIP 均在本地主机解析。卡内的远程链接不会被下载，头像预览使用包内资源。

素材卡片可搜索、分类、启停、复制和移出。详情里分别展示「本次使用」与「原文件已保存」。保存编辑会新增版本；已经开始的对话仍绑定原版本，需在对话中明确应用新版。移出素材库保留旧对话需要的版本与原件。

「导出原件」保留导入字节；「导出当前版本」输出约定的 JSON。角色输出 CCv3 JSON，未知字段随编辑内容保留。素材位置可在面板中查看。

## 留一张自己的名片

「新建我的人设」可保存昵称、人物设定和本地头像，按故事准备多套身份。开聊时选用一个版本；在对话中临时改称呼与设定只影响那段故事。改好库中的人设后，已有对话通过「应用到这段对话」更新。头像用于阅读身份，所用版本和本地图片随完整对话备份保留。

## 条目直接改，保存再生效

世界书提供关键词、内容、常驻、扫描／预算和插入位置等表单；预设支持提示词角色、内容、顺序与深度；正则可调整作用位置与显示／模型范围。样本文本在本地试运行，匹配、替换结果和规则错误当场可看，不消耗模型用量。

草稿点击「保存为新版本」后才写入素材库，已有对话保留原绑定。高级原始 JSON 入口与表单共用修订方法，未知扩展字段和原件继续保留。人设也能复制、移出、导出与重新导入。

适配基线：DeepSeek Harness 0.2.2-rc.3，Node.js 24。
